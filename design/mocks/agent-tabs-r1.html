Agent

Your AI agent connects to this extension to use your installed kits. The extension is the bridge, not the agent.
Grok Bot runs in its own VM. If you haven't set it up there yet (clone, install the host, load the extension), follow the setup guide ↗. Once its options page says ready for your agent, tell Grok Bot to use this endpoint:
http://127.0.0.1:4890/mcp
Then ask it, e.g. “list my LinkedIn invites via API for Any Site.”
