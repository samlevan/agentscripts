An API for the web — even for the sites that never built one.

Your agent has no built-in tools for most sites, so it improvises: reading and clicking pages, screenshot by screenshot — slow, unreliable, and burning tokens the whole way. API for Any Site installs small kits that give it direct, API-like tools instead: fast, reliable calls that return just the data, at a fraction of the cost. The API a site never published, running in your own logged-in session.

Why not just let my agent use the page?

An agent driving a web page has to look, screenshot, and click. That is slow, it breaks when the page changes, and it is expensive — every screenshot and page it reads burns tokens. A kit turns all of it into one direct tool call that returns just the data it needs: faster, sturdier, and a fraction of the cost. It works with any agent, and the daily limits and audit log come along for free.
